# Support

There are several ways to get help with git-unlocked depending on what you need.

---

## I have a question about Git, GitHub or GitLab

Start with the course itself - most questions are answered somewhere in the files.

- **[FAQ.md](FAQ.md)** - the most commonly asked questions, answered in detail
- **[09-reference/glossary.md](09-reference/glossary.md)** - every term defined clearly
- **[09-reference/common-mistakes.md](09-reference/common-mistakes.md)** - common errors and exactly how to fix them
- **[09-reference/cheatsheet.md](09-reference/cheatsheet.md)** - every Git command in one place

If your question is not covered, open a **[GitHub Discussion](https://github.com/zaccesss/git-unlocked/discussions)**. Discussions are the right place for questions, ideas and general conversation about the course content.

---

## I found an error or something is wrong in the course

Open a **[GitHub Issue](https://github.com/zaccesss/git-unlocked/issues)** and describe:

- Which file the error is in
- What is wrong
- What the correct information should be (if you know)

If you know how to fix it yourself, a pull request is even better. See [CONTRIBUTING.md](CONTRIBUTING.md) for how to do that.

---

## I want to suggest new content or a new topic

Open a **[GitHub Issue](https://github.com/zaccesss/git-unlocked/issues)** with the title format `suggestion: your idea here` and describe what you want to see and why it would help learners.

---

## I found a security issue

Do not open a public issue. See [SECURITY.md](SECURITY.md) for how to report security concerns privately.

---

## External resources

If you need help beyond this course:

- **[Official Git documentation](https://git-scm.com/doc)** - the complete reference
- **[GitHub documentation](https://docs.github.com)** - everything about GitHub
- **[GitLab documentation](https://docs.gitlab.com)** - everything about GitLab
- **[Stack Overflow](https://stackoverflow.com/questions/tagged/git)** - the largest community Q&A for Git questions
- **[Oh Shit, Git!?!](https://ohshitgit.com)** - practical fixes for common Git disasters
