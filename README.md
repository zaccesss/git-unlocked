## 🌍 Who This Is For

This course is for **everyone** - whether you have never heard of Git or you are a developer who wants to go deeper. It covers Windows, Mac and Linux at every step.

| Level           | You are...                       | Start here                                                    |
| --------------- | -------------------------------- | ------------------------------------------------------------- |
| 🟢 Beginner     | Brand new to Git                 | [What is version control?](git/01-what-is-version-control.md) |
| 🟡 Intermediate | Know the basics, want more       | [Branching](git/06-branching.md)                              |
| 🔴 Advanced     | Comfortable with Git, going deep | [Rebase](git/12-rebase.md)                                    |

## 🗺️ Learning Path

Follow this path if you are starting from zero. Skip ahead if you already know a section.

```
🟢 BEGINNER
│
├── 1. What is version control?
├── 2. Installing Git (Windows / Mac / Linux)
├── 3. How Git works
├── 4. Core concepts (repo, commit, branch, staging)
├── 5. Basic commands (init, add, commit, status, log)
├── 6. What is GitHub?
├── 7. Creating your GitHub account
└── 8. Pushing your first repo to GitHub

🟡 INTERMEDIATE
│
├── 9.  Branching and switching
├── 10. Merging branches
├── 11. Merge conflicts and how to fix them
├── 12. Remote repositories (origin, upstream)
├── 13. Pull requests
├── 14. .gitignore
└── 15. Stashing work

🔴 ADVANCED
│
├── 16. Rebase (rebase vs merge, interactive rebase)
├── 17. Cherry-pick
├── 18. Reset and revert
├── 19. Tags and releases
├── 20. Submodules
├── 21. Git hooks
└── 22. Bisect (finding broken commits)

🌐 PLATFORMS
│
├── GitHub (issues, PRs, Actions, Pages, security)
└── GitLab (merge requests, CI/CD pipelines)
```
