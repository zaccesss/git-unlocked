## 🛠️ How to Get Listed

1. Read [CONTRIBUTING.md](CONTRIBUTING.md)
2. Fork the repository
3. Make your contribution
4. Open a pull request
5. Once merged, you will be added here

All contributors are added in the order their first pull request was merged.

## 🌍 First Contribution Sandbox

Never made a pull request before? The [first-contribution](first-contribution/README.md) folder is a safe place to practise. Add your name to the contributors list there and make your very first open source contribution. It takes less than 5 minutes.
