## What is GitHub Education

GitHub Education is a set of free programs run by GitHub for students, teachers and schools. The goal is to give learners access to professional tools early so they can build real skills before entering the job market.

The main offerings are:

- **Student Developer Pack** - free tools for verified students
- **Teacher Benefits** - GitHub Team plan free for teachers
- **GitHub Classroom** - a platform for running coding assignments
- **Campus Expert Program** - leadership training for student community builders

Everything is free. Nothing requires a credit card as a student.

---

## The Student Developer Pack

The Student Developer Pack is the most valuable free resource available to any student studying technology. It is a collection of professional tools, platforms and services contributed by companies who want students to learn their products.

The total value of all offers is approximately $45,000 to $100,000+ depending on which tools you use. Most of that is cloud credits that are only valuable if you build at scale, but the day-to-day tools like Copilot Pro, JetBrains IDEs and domain names are genuinely useful immediately.

## How to Apply for the Student Developer Pack

**Requirements:**

- A GitHub account (free)
- Currently enrolled at an accredited school, college or university
- Aged 13 or older

**Step-by-step application:**

**Step 1.** Go to `education.github.com/pack` and click **Get Student Benefits**.

**Step 2.** Sign in to GitHub if you are not already signed in.

**Step 3.** Select **Student** when asked your role.

**Step 4.** Enter the name of your school. GitHub has a database of institutions - start typing and select from the dropdown.

**Step 5.** Provide your school email address if you have one. A school email ending in `.ac.uk`, `.edu`, `.ac`, or your institution's domain is the fastest way to verify. GitHub sends a verification email to confirm.

**Step 6.** If you do not have a school email or GitHub does not automatically verify your institution, you will be prompted to upload proof. Acceptable documents include:

- A student ID card (must show your name, institution name and a current date or expiry date)
- An official enrolment letter on institution letterhead
- A tuition payment receipt showing the current academic year

**Step 7.** Submit the application. GitHub reviews it, usually within 1 to 3 business days. You will receive an email when it is approved or if more information is needed.

**After approval:**

- Visit `education.github.com/pack` to browse and activate individual offers
- Each partner offer requires a separate redemption - click the offer and follow the partner's instructions
- GitHub Copilot Pro activates automatically on your GitHub account

## Troubleshooting Your Application

**"We could not verify your academic affiliation"**

This means GitHub could not automatically confirm your school. Solutions:

- Make sure you used your school email address (not a personal Gmail or similar)
- Check the email verification link in your inbox
- If you do not have a school email, upload a student ID card or enrolment letter as proof

**Uploaded document rejected:**

- The document must be legible and clearly show your institution name, your name and a date (expiry or issue) indicating current enrolment
- Crop the image to show the relevant information clearly
- Accepted formats: JPEG, PNG, PDF

**Application keeps asking for a document even with a school email:**

Some school email domains are not in GitHub's database. In this case, upload a student ID anyway - this is common for newer or smaller institutions.

**Benefits expired:**

Student Developer Pack benefits last for 2 years and can be renewed while you are still a student. Go to `education.github.com` and re-apply with fresh proof of enrolment.

**"I graduated - can I keep the benefits?"**

No. Benefits are for active students. After graduation, Copilot reverts to the free tier and partner offers expire. Some partners offer discounted rates for recent graduates - check each partner's site.

## Teacher Benefits

Verified teachers and academic staff get the **GitHub Team plan free** for their personal account and for up to 25 private repositories.

Team plan includes:

- Unlimited private repositories
- Protected branches
- Code owners
- Required reviewers
- GitHub Actions (3000 minutes/month)
- GitHub Packages (2GB storage)

**Apply at:** `education.github.com/teachers`

The application process is similar to students - verify with a school email or upload documentation showing you are employed by an educational institution (a staff ID or an employment letter on institutional letterhead).

## GitHub Classroom

GitHub Classroom is a free tool that allows teachers to automate the distribution, collection and grading of coding assignments using GitHub repositories.

**How it works:**

1. A teacher creates an **assignment** in Classroom linked to a **template repository** containing starter code
2. Students receive an **assignment link**
3. Each student clicks the link, which automatically creates a **private repository** in the classroom organisation, pre-populated with the starter code
4. Students work on their repository and push their code
5. The teacher can see all student repositories in one place and run automated tests

**Setting up GitHub Classroom:**

1. Go to `classroom.github.com`
2. Sign in with your GitHub account
3. Click **New classroom**
4. Link it to a GitHub organisation (create one if needed)
5. Invite students by sharing the classroom link - they join with their GitHub accounts

**Individual vs group assignments:**

Classroom supports both. Group assignments create one shared repository per group. Useful for team projects.

**Autograding:**

Classroom can run test suites automatically when a student pushes code. Set up autograding in the assignment settings by adding test commands. Results appear in the Classroom dashboard. Supports any language that can run tests from the command line.

**Feedback pull requests:**

Classroom automatically creates a feedback pull request on each student repository. Teachers leave code review comments there, which students can respond to.

> [!TIP]
> Even if you are a student reading this, understanding how Classroom works is useful. If a lecturer is distributing assignments via GitHub, this is the system they are using. Your assignment repository is a private fork of their template.

## Campus Expert Program

GitHub Campus Experts are student leaders who build technical communities at their universities. They run workshops, hackathons and study groups, and represent GitHub in their academic community.

**What Campus Experts get:**

- Training in public speaking, community building and technical education
- GitHub Campus Expert certification and profile badge
- Conference travel funding and event grants
- Access to GitHub staff and the global Campus Expert network
- Early access to GitHub products and betas

**Requirements to apply:**

- Currently enrolled student
- At least 18 years old
- Basic GitHub and Git knowledge
- Demonstrated interest in building community (existing club, past event, online presence)

**Application process:**

Applications open once or twice per year. The process includes a written application, a video introduction and a review by GitHub Education staff. It is competitive - roughly 100 to 200 new Experts are accepted per cohort globally.

**Apply at:** `education.github.com/experts`

> [!NOTE]
> The Campus Expert program is genuinely selective. If you are not ready yet, build something visible first - run a workshop at your university, contribute to open source, build a local developer community. Come back when you have something concrete to show.

## Try It Yourself

**Apply for the Student Developer Pack:**

1. Go to `education.github.com/pack`
2. Click **Get Student Benefits**
3. Complete the application with your school email or uploaded document
4. Wait for the approval email
5. Once approved, activate GitHub Copilot Pro first - it is the most immediately useful offer

**Activate a partner offer:**

1. Go to `education.github.com/pack` once approved
2. Find the JetBrains offer and click **Get access**
3. Follow JetBrains' instructions to link your GitHub account and activate a licence
4. Download and install any JetBrains IDE - PyCharm Community is free anyway, but Professional gives you database tools, full web support and profiling

## Common Mistakes

**Using a personal email instead of a school email.** A Gmail or Outlook address will not automatically verify you. Use your `.ac.uk`, `.edu` or institution email.

**Uploading an expired student ID.** The document must show you are currently enrolled. An ID that expired last year will be rejected.

**Not renewing benefits in second and third year.** Benefits last 2 years and need renewal. Set a calendar reminder to re-apply.

**Forgetting to activate individual offers.** Approval for the Pack does not automatically activate every tool. You must visit each partner's offer page and redeem it manually.

**Applying while not currently enrolled.** You must be actively enrolled. Deferrals and gaps in enrolment may affect eligibility.
