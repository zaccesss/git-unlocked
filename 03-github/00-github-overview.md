# GitHub - Folder Overview

**Difficulty:** 🟢 Beginner | **Time:** 5 minutes

This folder covers GitHub - the world's largest code hosting platform with over 180 million developers and more than 1 billion repositories. GitHub is built on top of Git and adds a web interface, collaboration tools, automation, security features, AI assistance and a global developer community.

If you are brand new to GitHub, start at file 01 and work forward. If you are looking for something specific, use the table below to jump straight to it. If you cannot find a feature, go directly to [27 - All GitHub features reference](27-all-github-features-reference.md).

## Note on operating system coverage

Every file in this folder covers **Windows**, **Mac** and **Linux** wherever commands differ. GitHub's web interface is identical across all operating systems. Command line examples use PowerShell on Windows and Bash on Mac and Linux. OS icons used throughout: 🪟 Windows, 🍎 Mac, 🐧 Linux.

---

## Note on GitHub vs Git

Git is the version control system. GitHub is a hosting platform built on top of Git. Everything in this folder is specific to GitHub. Features like pull requests, Actions, Copilot, Discussions, Projects and Codespaces exist only on GitHub - they are not part of Git itself. GitLab and Bitbucket offer similar but different features, covered in the `gitlab/` folder.
